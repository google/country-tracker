# Security Policy

## ⚠️ Security Proof of Concept Disclaimer
This project is provided "as is" without any guarantees or warranties of any kind. It is intended to be used as a fun proof of concept and learning resource.

While efforts have been made to secure the default configuration, security is paramount. Users are solely responsible for reviewing, configuring, and testing all backend security rules (e.g., Firestore rules, PocketBase API rules) and infrastructure settings before any production deployment.

A full, independent security review is strongly recommended for any production use.
