# Tech Stack

## Frontend
- **Programming Language:** TypeScript
- **Framework:** Next.js
- **UI Library:** Mantine

## Backend & Database
- **Platform/Database:** PocketBase (Default) / Firebase (Option)
  - **PocketBase**: Lightweight, single-file open-source backend with embedded SQLite.
  - **Firebase**: Firestore for database and Firebase Authentication for user authentication.

## Testing
- **Framework:** Jest
- **Library:** React Testing Library
